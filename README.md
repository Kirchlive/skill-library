# skill-library

Seventeen Claude Code skills that have no equivalent in any published plugin, bundled as one installable plugin.

## Install

```
/plugin marketplace add Kirchlive/skill-library
/plugin install skill-library@skill-library
```

## Skills

### Media generation

| Skill | What it does |
|---|---|
| `music-generation` | Generates, composes, or produces music and sound from a prompt. |
| `podcast-generation` | Turns text content into a podcast. |

### Documents and data

| Skill | What it does |
|---|---|
| `data-analysis` | Analyzes uploaded Excel and CSV files. |
| `chart-visualization` | Picks a chart form for the data and renders it. |
| `consulting-analysis` | Writes professional research and consulting-style analysis. |
| `newsletter-generation` | Drafts newsletters and email campaigns. |
| `topic-bookmarks-reorganizer` | Reorganizes a browser bookmarks export by topic and deduplicates URLs. |

### Code and documentation

| Skill | What it does |
|---|---|
| `code-documentation` | Generates and improves documentation for code. |
| `good-docs-writer` | Writing guidance for documentation. |
| `skill-reviewer` | Reviews skill packages for readiness, triggers, safety boundaries, resources, and evals. |

### Interface and workflow

| Skill | What it does |
|---|---|
| `web-design-guidelines` | Reviews UI code against the Web Interface Guidelines. |
| `master-wave-governance` | Planning-and-execution protocol for repositories using MASTERPLAN/wave governance. |
| `skill-routing` | Picks the skills a task needs and loads them before the work starts. |
| `browser` | Drives the user's real, logged-in browser through the claude-browser MCP tools. |
| `opentabs` | Works with the browser's open tabs. |
| `think-in-config-language` | Makes extended thinking follow the `language` setting in the Claude Code config. |
| `surprise-me` | Discovers something in the current context and builds an unexpected demo from it. |
